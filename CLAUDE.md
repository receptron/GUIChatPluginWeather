# CLAUDE.md

## Plugin Overview

Weather forecast plugin for GUI Chat. Display weather information from Japan Meteorological Agency.

## Common Guidelines

For standard plugin development guidelines, see:
https://github.com/receptron/GUIChatPluginTemplate/blob/main/CLAUDE.md

## Plugin-Specific Notes

### Features
- Weather forecast display
- Japan Meteorological Agency data
- Location-based forecasts

### External Services
- **Japan Meteorological Agency API**: Weather data source

### Dependencies
- `gui-chat-protocol`: Core protocol for GUI Chat plugins
